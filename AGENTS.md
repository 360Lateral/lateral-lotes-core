# UI rules
- Market cards and lot detail use `calcularScore360` on the eight stored module scores from `vw_lotes_publicos` and render `Score360Badge`; this prevents derived analysis formulas from replacing the stored scores. Enrich only catalog IDs authorized by the existing RPC, without changing database access. When the view is inaccessible or RLS hides a row, use the existing authorized catalog RPC (currently exposes only three module scores), never privileged credentials or synthetic scores.
- Keep the compact mobile action menu scoped to `/mercado` and `/lotes/:id` in `FloatingActionStack`; preserve the existing actions on other routes and desktop to avoid unrelated UI changes.
- Keep mobile lot-detail zoom controls in `MapaHeroLote` and reuse the centralized map loader; this allows accessible touch targets without changing desktop map controls.
